# PromptLab · 本地提示词自动调优

PromptLab 是独立的本地优先提示词工程工具。它把「优化」定义为可验证的候选搜索：先跑原版建立基线，再根据目标和调优样例生成候选；本机模型逐例执行，评审模型按验收标准盲评；失败时用训练样例反馈进行有限轮次修订。独立回归样例不提供给优化器，只用于检查候选是否退化。即使通过门槛，也要由用户检查输出并手动采纳。

## 运行

需要 Windows、已启动的 Ollama 和至少一个本地模型。默认复用已安装的 `qwen3-vl:4b`。使用 .NET 10 SDK 时从源码启动：

```powershell
dotnet run --project .\PromptLab.csproj -c Release
```

浏览器打开 <http://127.0.0.1:5181>。也可运行 `start.ps1`；首次会发布为自包含 Windows 单文件，之后无需单独安装 .NET Runtime。

可选环境变量 `PROMPTLAB_OLLAMA_URL` 用于更改 Ollama 地址，但程序只接受回环地址 `127.0.0.1` 或 `localhost`。提示词调优记录保存在 `%LOCALAPPDATA%\PromptLab\runs`。编辑草稿保存在当前浏览器的本地存储。工作包与评测报告可导入/导出为可读 JSON；不需要云账户、API Key 或远端服务。

## 工作流程和保护

1. 写目标、原始提示词、整体验收标准，添加代表性测试用例。
2. 至少标记一条**调优集**和一条独立**回归集**。调优集用于诊断和生成反馈；回归集只参与最终评分，不进入候选生成上下文。对于答案确定的转换任务，可填写期望输出走确定性精确匹配；开放式任务留空，由本机模型按用例 rubric 辅助评分。
3. 本机模型串行执行原版和候选提示词，盲评模型按用例标准给 0–5 分，并在最多 3 轮内保留最佳候选。
4. 候选整体分数必须严格高于原版，且独立回归集不得低于原版，才可采纳；同分不会被当成已验证的提升。否则界面会锁住采纳按钮。用户决定、备注、阶段与每次评测都保存在本地报告中。

评分是同一个模型生成的辅助信号，不等于真实质量证明；样例标准质量决定了评测的可信度。对于重要的提示词，请增加覆盖边界输入的独立回归集，并人工检查每条输出。执行测试时，Ollama 获得对应提示词和用例文本；PromptLab 不给模型开放 shell、文件或浏览器工具。

模板支持 `{{input}}` 占位符；未写占位符时，测试输入会追加在提示词末尾。最多支持 12 条用例、每次 1–3 轮调优。仅允许发送至回环 Ollama 服务。

## 开源参考

用户指定的 [`Haozhe-Xing/agent_learning`](https://github.com/Haozhe-Xing/agent_learning) 是 Agent 工程教程而非现成优化器。PromptLab 采用其评估、安全与自我改进的工程思路，并把生产声称限制在当前可验证的实现范围内。

另外参考：

- [`block/buzz`](https://github.com/block/buzz)：阶段记录与人工决定共用一条可追溯日志的思路。PromptLab 用本地 JSON 保存运行轨迹和人工决定，没有引入其 Nostr relay 或多成员服务端。
- [`OpenMinis/OpenMinis`](https://github.com/OpenMinis/OpenMinis)：本地设备优先与明确的人类反馈闭环。PromptLab 将模型连接固定到本机 Ollama，不接入云模型、设备工具或移动端系统权限。
- [`nyblnet/bento`](https://github.com/nyblnet/bento)：人类可读、便携、便于回退的数据格式。PromptLab 的工作包和评测报告是开放 JSON 文件，历史候选保留为独立记录。

目前只借鉴上述项目的设计思路，没有复制其代码。它们各自的许可协议和架构不作为 PromptLab 依赖。
